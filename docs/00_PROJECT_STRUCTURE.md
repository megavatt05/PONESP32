### Принцип проектирования

Проект построен по принципу **Fail-Safe** (отказоустойчивость):

- Любой физический отказ (обрыв провода, открытие двери, потеря связи) → **остановка**.
- Самопроизвольный пуск исключён.
- Соответствие **ГОСТ Р МЭК 60204-1**.

### Оборудование

| Компонент | Модель |
|-----------|--------|
| Частотный преобразователь | EasyDrive MINI-S-2S0004M |
| Плата управления | cv-lkdv1.0.2 / mini-s-lkvd v2/1 |
| Напряжение питания | 220 В AC |
| Управление | RS-485 Modbus RTU + сенсорный экран / ESP32 |
| Датчик двери | Стеклянный геркон + магнит |
