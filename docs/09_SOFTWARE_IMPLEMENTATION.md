# 09. Реализация программного обеспечения

## Выбор платформы

| Платформа | Плюсы | Минусы | Рекомендация |
|-----------|-------|--------|--------------|
| **ESP32 + PlatformIO** (C++) | Уже есть в репозитории, дешево, RS-485 легко | Нужен дисплей отдельно | Хорошо для встраивания |
| **HMI (EKF / Coolmay / Haiwell)** | Готовый сенсорный экран, Modbus Master | Сложнее кастомная логика | Лучше для оператора |
| **Python (pymodbus)** на ПК/Raspberry | Быстрая разработка, удобный UI | Не промышленный вариант | Для отладки и стенда |
| **C# / .NET** | Удобный GUI | Требует ПК | Для стационарного пульта |

**Рекомендация для данного проекта:**  
Основной вариант — **HMI 7" с Modbus RTU Master** + резервный/отладочный код на **ESP32** (ветка `esp32c3-modbus-rtu` и `rs485-motor-control`).

## Минимальный шаблон логики (псевдокод)

```
loop every 200 ms:
    status = read(3000H)
    fault  = read(3001H)

    if no response or fault != 0:
        disable Start button
        show "Авария / Нет связи"
        continue

    write(2001H, 1000)          # 10.00 Гц безопасный старт
    enable Start button

    if operator pressed Start:
        write(2000H, 0x0001)    # СТАРТ
        wait until status == 2 and frequency rising
        write(2001H, work_freq) # рабочая частота

        while running:
            rpm = read(1004H)
            fault = read(3001H)
            if fault != 0 or communication lost:
                write(2000H, 0x0005)  # СТОП
                break
```

## Что уже есть в репозитории

| Ветка | Содержание |
|-------|------------|
| `main` | Документация + базовая структура |
| `develop` | ESP32 + дисплей + энкодер + RS485 |
| `rs485-motor-control` | Arduino/PlatformIO управление по Serial + Modbus |
| `esp32c3-modbus-rtu` | ESP32-C3 + ESP-IDF 6.1, циклы пуск/стоп |
