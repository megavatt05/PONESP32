# 05. Карта регистров Modbus RTU

**Протокол:** Modbus RTU  
**Адрес slave:** 1  
**Скорость:** 19200, 8-N-1

## Запись (Function 06 / 10H)

| Адрес hex | Адрес dec | Назначение | Значения |
|-----------|-----------|------------|----------|
| **2000H** | 8192 | Регистр команд | `0001H` = СТАРТ вперёд<br>`0005H` = СТОП с замедлением<br>`0008H` = Сброс ошибки |
| **2001H** | 8193 | Задание частоты | Формат ×100<br>10.00 Гц → `1000`<br>50.00 Гц → `5000` |

## Чтение (Function 03)

| Адрес hex | Адрес dec | Назначение | Значения |
|-----------|-----------|------------|----------|
| **3000H** | 12288 | Состояние ПЧ | `1` = Остановлен / Готов<br>`2` = В работе |
| **3001H** | 12289 | Код ошибки | `0` = Норма<br>`>0` = код аварии |
| **1001H** | 4097 | Выходная частота | Формат ×100 |
| **1004H** | 4100 | Скорость вращения, об/мин | Основной регистр мониторинга |

## Коды ошибок (часто используемые)

| Код | Описание |
|-----|----------|
| Err15 | Внешняя авария (DI3 / геркон) |
| Err17 | Таймаут связи (Watchdog) |
