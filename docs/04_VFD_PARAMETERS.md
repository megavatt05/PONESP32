# 04. Параметры EasyDrive MINI-S

Частотный преобразователь: **EasyDrive MINI-S-2S0004M**  
Плата управления: **cv-lkdv1.0.2 / mini-s-lkvd v2/1**

## 1. Параметры защиты и входов

| Параметр | Значение | Назначение |
|----------|----------|------------|
| **P05.02** | **11** | DI3 = «Внешняя авария» (External Fault). Размыкание геркона → Err15 |

## 2. Параметры для лабораторного стенда (лампы)

| Параметр | Значение | Назначение |
|----------|----------|------------|
| **P00.00** | **2** | Скалярный режим V/F (обязательно для ламп) |
| **P11.04** | **0** | Отключение защиты от обрыва выходной фазы |

## 3. Параметры сети Modbus (группа P13)

| Параметр | Значение | Назначение |
|----------|----------|------------|
| **P13.00** | **1** | Адрес slave (Slave ID = 1) |
| **P13.01** | **4** | Скорость 19200 бод |
| **P13.02** | **0** | Формат 8-N-1 |
| **P13.03** | **1.0** | Таймаут связи Watchdog = 1,0 с |
| **P13.04** | **0** | При таймауте: плавное замедление + авария Err17 |

## 4. Рекомендуемые технологические параметры

| Параметр | Рекомендация | Примечание |
|----------|--------------|------------|
| Время разгона | 2–5 с | Безударный пуск (S-кривая по возможности) |
| Время торможения | 2–5 с | Чтобы не рвать материал |
| Стартовая частота | 10.00 Гц | Записывается программно в 2001H |
| Рабочая частота | по технологии (обычно 30–50 Гц) | |
