# Modbus карта регистров

## Holding registers (FC03 / FC06 / FC16)

| Адрес         | Значение | Действие         |
| ------------- | -------- | ---------------- |
| 8192 (0x2000) | `18`     | ПУСК двигателя   |
| 8192 (0x2000) | `1`      | СТОП двигателя   |
| 8193 (0x2001) | `1000`   | Скорость разгона |

## Формат запроса ПУСК

```
[1][06][20 00][00 12][CRC]
```

## Формат запроса СТОП

```
[1][06][20 00][00 01][CRC]
```

## Формат запроса "разгон = 1000"

```
[1][06][20 01][03 E8][CRC]
```
