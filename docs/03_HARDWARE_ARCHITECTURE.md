# 03. Аппаратная архитектура

## 1. Общая схема

```
[Сеть 220 В]
      │
[Вводной автомат + УЗО]
      │
[Шкаф IP54]
      ├── EasyDrive MINI-S (частотник)
      ├── Блок питания 24 В
      ├── Кнопка E-Stop (грибок)
      ├── Геркон двери → DI3
      └── HMI / ESP32 ←→ RS-485 ←→ ПЧ
      │
[Двигатель] ←── U V W
```

## 2. Физическая защита двери (Fail-Safe)

Используется **стеклянный геркон** на замыкание + магнит.

| Состояние | Контакты геркона | Сигнал на DI3 | Результат |
|-----------|------------------|---------------|-----------|
| Дверь закрыта | Замкнуты | +24 В | Работа разрешена |
| Дверь открыта | Разомкнуты | 0 В | ПЧ снимает выход, Err15 |
| Обрыв кабеля | Разомкнуты | 0 В | То же самое (Fail-Safe) |

**Схема подключения:**

```
[Клемма ПЧ +24V] ───> [Стеклянный геркон] ───> [Клемма ПЧ DI3]
```

**Параметр EasyDrive:**
- `P05.02 = 11` — DI3 = «Внешняя авария» (External Fault)

## 3. Аппаратный E-Stop (рекомендуется)

Кнопка «Грибок» с фиксацией (1НЗ) должна аппаратно разрывать цепь разрешения пуска независимо от ПО.

## 4. RS-485

- Один slave (частотник)
- Скорость 19200 бод
- Терминатор 120 Ом на конце линии (рекомендуется)
