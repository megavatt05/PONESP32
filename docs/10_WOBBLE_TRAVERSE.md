# 10. Функция качающейся частоты (Wobble / Traverse)

Специализированная функция для **намоточных** и текстильных машин.

## Зачем нужна

При постоянной скорости витки провода ложатся друг на друга и «врезаются» на краях барабана.  
Качающаяся частота заставляет выходную частоту ПЧ **плавно колебаться** вокруг базовой (например, 40 Гц ± 2 Гц) по **треугольному** закону. Витки укладываются ромбиком — равномерно и без навалов.

```
Частота
  ▲
  │      /\      /\      /\
  │     /  \    /  \    /  \
  │────/────\──/────\──/────\──── базовая (центр)
  │   /      \/      \/
  │
  └──────────────────────────▶ время
```

## Как работает совместно с RS-485

1. По Modbus вы задаёте **базовую (центральную) скорость** — регистр `2001H` (например, 4000 = 40.00 Гц).
2. В параметрах ПЧ включается режим Wobble (группа **P7**).
3. Частотник **сам** качает частоту вокруг заданного центра. Контроллеру не нужно постоянно менять задание.

## Параметры EasyDrive MINI-S (группа P7)

| Параметр | Название | Диапазон | Рекомендация для намотки |
|----------|----------|----------|---------------------------|
| **P7.00** | Режим программного хода / Wobble | — | Включить режим качания (см. руководство, значение для Wobble) |
| **P7.11** | Параметры работы Wobble | битовое | Фиксированная амплитуда, старт с предустановки |
| **P7.12** | Предустановочная частота Wobble | 0…Fmax | Обычно = стартовая безопасная (10 Гц) |
| **P7.13** | Время ожидания на предустановке | 0…3600 с | 0–2 с |
| **P7.14** | **Амплитуда качания** | 0.0…50.0 % | **5–10 %** (при 40 Гц и 5 % → ±2 Гц) |
| **P7.15** | Скачок частоты (jump) | 0…50 % от амплитуды | 0 или малый (для мягкой укладки) |
| **P7.16** | **Период цикла качания** | 0.1…3600 с | **5–15 с** (зависит от диаметра и шага) |
| **P7.17** | Доля времени нарастания (треугольник) | 0…100 % | **50 %** (симметричный треугольник) |
| **P7.18** | Центральная частота Wobble | 0…Fmax | Можно задать здесь **или** через Modbus 2001H |

### Пример настройки «±2 Гц вокруг 40 Гц, период 10 с»

| Параметр | Значение | Смысл |
|----------|----------|-------|
| Центр (2001H или P7.18) | 40.00 Гц | Базовая скорость намотки |
| P7.14 | 5.0 % | 5 % от верхней частоты ≈ ±2 Гц при Fmax≈50–80 Гц* |
| P7.16 | 10.0 с | Полный цикл туда-обратно |
| P7.17 | 50.0 % | Равносторонний треугольник |
| P7.15 | 0 % | Без резкого скачка |

\* Точная формула в руководстве:  
`ширина качания = P7.14 × верхний предел частоты` (при фиксированном режиме).

Подбирайте P7.14 так, чтобы фактический размах был **±1.5…3 Гц** — этого обычно достаточно для ровной укладки.

## Рекомендуемый порядок включения

1. Настроить P7.xx **с панели ПЧ** (или один раз записать через Modbus, если адреса параметров известны).
2. В управляющей программе:
   - как обычно: диагностика → 10 Гц → Пуск;
   - после разгона записать **рабочий центр** в `2001H` (например, 40.00 Гц);
   - ПЧ сам начнёт качать частоту вокруг этого центра.
3. Мониторить `1001H` (выходная частота) — будет видно «гуляние» вокруг базы.
4. При Стоп — качание прекращается вместе с остановом.

---

## Связь с алгоритмом Fail-Safe

| Этап алгоритма | Действие Wobble |
|----------------|-----------------|
| Шаг 1–2 (диагностика, 10 Гц) | Wobble ещё не активен или на предустановке |
| Шаг 3–4 (Пуск, разгон) | Выход на центр / предустановку |
| Шаг 5 (рабочий режим) | **Wobble активен** — частота качается вокруг 2001H |
| Стоп / авария / Watchdog | Качание останавливается вместе с двигателем |

Аппаратные защиты (геркон, E-Stop) работают **независимо** от Wobble.

## Альтернатива: программный Wobble на ESP32

Если параметры P7 недоступны по Modbus или неудобны, контроллер может сам периодически менять `2001H`:

```
center = 40.00 Гц
amplitude = 2.00 Гц
period = 10 с

каждые 50–100 мс:
  phase = (millis % period) / period   # 0…1
  // треугольный сигнал
  if phase < 0.5:
    f = center - amplitude + 4*amplitude*phase
  else:
    f = center + amplitude - 4*amplitude*(phase-0.5)
  write 2001H = f * 100
```

Минусы: лишний трафик Modbus, зависимость от стабильности связи.  
Плюсы: гибкая настройка с HMI/UART без меню ПЧ.

В прошивке `esp32c3-modbus-rtu` предусмотрен **программный Wobble** (команды `W` / `w`) — см. README ветки.

---

## Итог для намоточного станка

1. Задайте базу скорости по RS-485 (`2001H`).
2. Включите Wobble в ПЧ (P7) **или** программный Wobble на ESP32.
3. Амплитуда ±1.5…3 Гц, период 5–15 с — типичный старт для подбора.
4. Контролируйте укладку визуально и при необходимости подстройте P7.14 / P7.16.
