# 01. Техническое задание

## 1. Назначение системы

Система управления намоточным станком предназначена для:

- Разматывания материала с одной катушки
- Протяжки через редуктор и мерный механизм
- Намотки на приёмную катушку
- Управления скоростью и длиной намотки
- Обеспечения безопасного пуска/останова по требованиям промышленной безопасности

## 2. Исходные данные

| Параметр | Значение |
|----------|----------|
| Питание | 220 В AC, 50 Гц |
| Привод | Асинхронный двигатель через частотный преобразователь |
| Частотник | EasyDrive MINI-S-2S0004M (плата cv-lkdv1.0.2 / mini-s-lkvd v2/1) |
| Интерфейс управления | RS-485, протокол Modbus RTU |
| Операторский интерфейс | Сенсорный экран (HMI) и/или ESP32 + дисплей |
| Защита двери | Геркон + магнит (Fail-Safe) |
| Мерный механизм | Датчик длины / энкодер (опционально) |

## 3. Функциональные требования

1. Пуск двигателя только после подтверждения готовности частотника и закрытия двери.
2. Предварительная установка безопасной стартовой частоты (10 Гц).
3. Плавный разгон до рабочей частоты.
4. Непрерывный мониторинг оборотов и аварий.
5. Аварийный останов при:
   - открытии двери;
   - обрыве кабеля геркона;
   - потере связи Modbus (Watchdog);
   - ошибке частотника;
   - нажатии аппаратной кнопки E-Stop.
6. Запрет самопроизвольного пуска при подаче питания или восстановлении связи.

## 4. Нефункциональные требования

- Соответствие **ГОСТ Р МЭК 60204-1**
- Принцип Fail-Safe
- Возможность лабораторного тестирования без двигателя (на лампах)
- Документирование всех параметров и регистров
