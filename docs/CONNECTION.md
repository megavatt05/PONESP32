# Схема подключения

## ESP32 → RS485 (MAX485 / XY-017)

| ESP32     | RS485 модуль      | Примечание              |
| --------- | ----------------- | ----------------------- |
| GPIO16    | RO (Receiver Out) | RX ESP32                |
| GPIO17    | DI (Driver In)    | TX ESP32                |
| GPIO27    | DE + RE           | Управление направлением |
| GND       | GND               | Общая земля             |
| 3.3V / 5V | VCC               | Зависит от модуля       |

## RS485 → Двигатель (драйвер)

| RS485 (A/B) | Драйвер двигателя |
| ----------- | ----------------- |
| A (+)       | A / D+            |
| B (–)       | B / D–            |
| GND         | GND (опционально) |

## Терминаторы

Если длина линии > 10 м или скорость > 9600 — установите
терминаторы 120 Ом между A и B на обоих концах линии.

## Параметры Modbus

- Скорость: **9600 бод**
- Формат: **8N1**
- Адрес ведомого: **1**
- Таймаут: **200 мс**
