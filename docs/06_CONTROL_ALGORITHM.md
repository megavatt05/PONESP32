# 06. Пошаговый алгоритм управления (Fail-Safe)

Алгоритм соответствует требованиям **ГОСТ Р МЭК 60204-1** и принципу «любой отказ → останов».

## Блок-схема (по ГОСТ 19.701-90)

```
┌────────────────────────────────────────────────────────────────────────┐
│ ШАГ 1. ЦИКЛ ДИАГНОСТИКИ И ЗАЩИТЫ ОТ САМОПРОИЗВОЛЬНОГО ПУСКА            │
│ ─ Опрос по таймеру (каждые 200 мс) регистров 3000H и 3001H.            │
│ ─ Кнопка "Пуск" на экране заблокирована (серая).                       │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                От ПЧ получен ответ? И Ошибок нет (3001H == 0)?
                ├── НЕТ ──> Кнопка заблокирована. Вывод: "Авария" / "Нет связи"
                │
                └── ДА
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ ШАГ 2. ПРЕДУСТАНОВКА БЕЗОПАСНОЙ СТАРТОВОЙ ЧАСТОТЫ                      │
│ ─ Запись значения 1000 (10.00 Гц) в регистр 2001H.                     │
│   Это исключает стартовый рывок и обрыв нити/провода.                  │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                          Запись подтверждена от ПЧ?
                          └── ДА
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ ШАГ 3. СНЯТИЕ БЛОКИРОВКИ И ОЖИДАНИЕ ДЕЙСТВИЯ                           │
│ ─ Кнопка "Пуск" становится активной (зелёной).                         │
│ ─ Программа ждёт физического нажатия кнопки оператором.                │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                         Оператор нажал кнопку "ПУСК"
                         └── ДА (импульс 0001H → 2000H)
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ ШАГ 4. КОНТРОЛЬ ВЫХОДА НА СКОРОСТЬ (РАЗГОН)                            │
│ ─ Опрос частоты (1001H) каждые 100 мс.                                 │
│ ─ Проверка статуса "В работе" (3000H == 2).                            │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                         Разгон до 10 Гц завершён штатно?
                         └── ДА
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ ШАГ 5. РАБОЧИЙ РЕЖИМ НАМОТКИ И СКОРОСТНОЙ МОНИТОРИНГ                   │
│ ─ Запись рабочей частоты (например 50.00 Гц) в 2001H.                  │
│ ─ Цикл опроса каждые 50 мс:                                            │
│   1. Чтение 1004H — обороты (RPM) на экран.                            │
│   2. Чтение 3001H — сброс Watchdog + проверка аварий.                  │
└────────────────────────────────────────────────────────────────────────┘
```

## Ключевые правила безопасности

1. Кнопка «Пуск» **никогда** не активна, пока нет подтверждённой готовности ПЧ.
2. Команда СТАРТ формируется **только по фронту** нажатия оператора.
3. При любой потере связи или ошибке — плавный останов (P13.04 = 0).
4. Аппаратный геркон и E-Stop работают независимо от ПО.
