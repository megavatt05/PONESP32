# 02. Соответствие ГОСТам безопасности

## Применяемые стандарты

| Стандарт | Область |
|----------|--------|
| **ГОСТ Р МЭК 60204-1-2007** | Электрооборудование машин |
| **ГОСТ 12.2.003-91** | Общие требования безопасности производственного оборудования |
| **ГОСТ ISO 14118-2023** | Предотвращение непреднамеренного пуска |
| **ГОСТ ISO 14119** | Блокировочные устройства |
| **ГОСТ IEC 61439** | Низковольтные комплектные устройства (щиты) |
| **ГОСТ 14254** | Степени защиты IP |
| **ТР ТС 010/2011** | Технический регламент «О безопасности машин и оборудования» |

## Соответствие алгоритма

| Требование стандарта | Реализация в проекте | Статус |
|----------------------|----------------------|--------|
| Контроль исправности цепей | Опрос 3000H и 3001H перед пуском | Полное |
| Блокировка кнопки «Пуск» | Программная блокировка до готовности ПЧ | Полное |
| Защита от случайного рывка | Предзапись 10.00 Гц в 2001H | Полное |
| Контроль линии связи | Watchdog P13.03 = 1.0 с → Err17 | Полное |
| Аппаратная блокировка двери | Геркон на DI3 (External Fault) | Полное |
| Защита от обрыва провода | Размыкание цепи геркона = авария | Полное |
| Запрет самопроизвольного пуска | Пуск только по фронту команды оператора | Полное |

## Рекомендации

- Добавить аппаратную кнопку **E-Stop** (категория 0/1) по ГОСТ Р МЭК 60204-1.
- Оформить блок-схему алгоритма по **ГОСТ 19.701-90** (см. документ 06).
