# Changelog

## [1.0.0] - 2025-01-XX
### Added
- Управление двигателем через RS485/Modbus RTU
- Команды ПУСК (`D`) и СТОП (`#`)
- Установка скорости разгона (регистр 8193)
- Ввод целевой длины с клавиатуры
- Эмуляция энкодера (`+` / `-`) для тестов без железа
- Логирование операций в Serial Monitor

### Removed
- Удалены TFT_eSPI, Keypad, ESP32Encoder, Adafruit_XCA9554, Wire
  (тестирование через терминал)
