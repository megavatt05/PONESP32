# ESP32-C3 → EasyDrive MINI-S (Modbus RTU)

**ESP-IDF 6.1.0** | Fail-Safe алгоритм | Управление через **UART** (Serial Monitor)

Соответствует **ГОСТ Р МЭК 60204-1** и регламенту намоточного станка.

---

## Возможности

- Диагностика ПЧ (регистры 3000H / 3001H) каждые 200 мс
- Блокировка команды «Пуск» до готовности частотника
- Предустановка безопасной частоты **10.00 Гц**
- Пуск / Стоп / Сброс ошибки по командам UART
- Контроль разгона и переход на рабочую частоту
- Мониторинг оборотов (RPM, регистр 1004H)
- Реакция на потерю связи и аварии ПЧ

## Пины RS485 (3 шт)

| Сигнал | GPIO |
|--------|------|
| TX     | 7    |
| RX     | 6    |
| DE     | 5    |

Скорость: **19200** 8N1 (P13.01 = 4 на EasyDrive)

## Команды UART (115200)

| Клавиша | Действие |
|---------|----------|
| `D` / `d` | **Пуск** (только если разрешён) |
| `S` / `s` | **Стоп** |
| `R` / `r` | Сброс ошибки ПЧ |
| `+` / `-` | Рабочая частота ±1 Гц |
| `H` / `h` | Справка |

## Параметры EasyDrive (обязательно)

```
P05.02 = 11    # DI3 = внешняя авария (геркон)
P13.00 = 1     # адрес = 1
P13.01 = 4     # 19200 бод
P13.02 = 0     # 8N1
P13.03 = 1.0   # Watchdog 1 с
P13.04 = 0     # плавный останов при потере связи
```

Для стенда на лампах:
```
P00.00 = 2     # V/F
P11.04 = 0     # отключить обрыв фазы
```

## Сборка

```bash
git clone -b esp32c3-modbus-rtu https://github.com/megavatt05/PONESP32.git
cd PONESP32
pio run -t upload
pio device monitor
```

## Алгоритм (кратко)

1. Опрос статуса/аварии → кнопка Пуск заблокирована  
2. Запись 10.00 Гц → Пуск разрешён  
3. Оператор нажимает `D` → команда СТАРТ  
4. Контроль разгона → переход на рабочую частоту  
5. Мониторинг RPM + Watchdog  

Полная документация: ветка `main` → `docs/06_CONTROL_ALGORITHM.md`
