# RS485 Motor Control (ESP32)

Проект управления двигателем через интерфейс **RS485 / Modbus RTU** на базе **ESP32**.
Управление осуществляется через последовательный порт (USB Serial) с любого терминала (Arduino Serial Monitor, PuTTY, minicom и т.д.).

## ✨ Возможности

- Запуск двигателя командой `D`
- Плавный разгон (установка скорости разгона)
- Остановка двигателя командой `#` (с проверкой достижения целевой длины)
- Эмуляция энкодера (`+` / `-`) для тестирования без физического датчика
- Ввод целевой длины с клавиатуры
- Логирование всех команд в Serial Monitor

## 🔌 Подключение (по умолчанию)

| ESP32        | RS485-модуль                      |
| ------------ | --------------------------------- |
| GPIO16 (RX2) | RO                                |
| GPIO17 (TX2) | DI                                |
| GPIO27       | DE + RE (управление направлением) |
| GND          | GND                               |
| 3.3V / 5V    | VCC                               |

> ⚠️ Питание RS485-модуля зависит от модели. Многие работают от 5 В, но линии DI/RO совместимы с 3.3 В логикой ESP32.

Полная схема — в [`docs/CONNECTION.md`](docs/CONNECTION.md).

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
```bash
git clone https://github.com/megavatt05/PONESP32.git
cd PONESP32
git checkout rs485-motor-control
```
2. Откройте `src/main.cpp` в Arduino IDE.
3. Установите библиотеку **iarduino_Modbus** через менеджер библиотек.
4. Выберите плату **ESP32 Dev Module** и загрузите скетч.
5. Откройте **Serial Monitor** на скорости **115200**.

## 🎮 Управление

| Клавиша      | Действие                                           |
| ------------ | -------------------------------------------------- |
| `0`–`9`, `.` | Ввод целевой длины                                 |
| `*`          | Сброс введённой длины                              |
| `+`          | Эмуляция: увеличить текущее расстояние на 0.1      |
| `-`          | Эмуляция: уменьшить текущее расстояние на 0.1      |
| `D`          | **Пуск** двигателя + установка скорости разгона    |
| `#`          | **Стоп** двигателя (если достигнута целевая длина) |

## 📋 Modbus карта регистров

| Регистр | Значение | Описание         |
| ------- | -------- | ---------------- |
| 8192    | `18`     | Команда ПУСК     |
| 8192    | `1`      | Команда СТОП     |
| 8193    | `1000`   | Скорость разгона |

Подробнее — в [`docs/MODBUS_MAP.md`](docs/MODBUS_MAP.md).

## ⚙️ Параметры (main.cpp)

```cpp
#define RXD2 16 // RX пин RS485
#define TXD2 17 // TX пин RS485
SoftwareSerial rs485(RXD2, TXD2);
ModbusClient modbus(rs485, 27); // 27 — пин DE/RE
```
