# PONESP32

Универсальная платформа на ESP32 с управлением поворотным энкодером, SPI-дисплеем, RS485-каналом, I2C-клавиатурой и WiFi.

## 🧩 Компоненты

| Компонент           | Примечание                                             |
| ------------------- | ------------------------------------------------------ |
| ESP32 Dev Module    | ESP32-WROOM-32, 4 MB flash                             |
| Ротационный энкодер | 2 пина + кнопка, аппаратное квадратурное декодирование |
| TFT-дисплей         | 480×320 SPI (ILI9488) или 320×240 (ILI9341)            |
| Трансивер RS485     | MAX485 / MAX3485 (3.3V)                                |
| I2C-клавиатура      | Адрес по умолчанию `0x50`                              |
| WiFi                | STA-режим                                              |

## 📌 Распиновка

| Функция  | GPIO | Примечание                       |
| -------- | ---- | -------------------------------- |
| ENC_CLK  | 13   | Квадратурный канал A             |
| ENC_DT   | 14   | Квадратурный канал B             |
| ENC_SW   | 15   | Кнопка энкодера (INPUT_PULLUP)   |
| TFT_CS   | 5    | Chip select дисплея              |
| TFT_DC   | 2    | Data/Command                     |
| TFT_PWR  | 12   | Управление питанием / EN дисплея |
| RS485_DE | 4    | DE/RE трансивера                 |
| RS485_RX | 16   | RO → UART2 RX                    |
| RS485_TX | 17   | DI ← UART2 TX                    |
| I2C SDA  | 21   | По умолчанию ESP32               |
| I2C SCL  | 22   | По умолчанию ESP32               |

> Дисплей использует аппаратный VSPI: `MOSI=23`, `SCK=18`, `MISO=19`.

## 🚀 Сборка и прошивка

```bash
# Установить PlatformIO Core
pip install platformio

# Сборка
pio run

# Прошивка
pio run -t upload

# Монитор порта
pio device monitor
```

Или через **PlatformIO IDE** в VSCode: панель PlatformIO → `Build` / `Upload`.

## ⚙️ Настройка

1. Откройте `src/main.cpp`
2. Замените:
```cpp
#define WIFI_SSID "your_SSID"
#define WIFI_PASSWORD "your_PASSWORD"
#define I2C_KEYBOARD_ADDR 0x50
```
3. При необходимости измените распиновку в блоке `Configuration`.

## 📺 Дисплей 480×320 (ILI9488)

В `platformio.ini` раскомментируйте:

```ini
; adafruit/Adafruit ILI9488@^1.6.0
```

И в `src/main.cpp` замените тип на `Adafruit_ILI9488` + константы цвета `ILI9341_*` → `ILI9488_*`.

Альтернатива — **TFT_eSPI** (быстрее и больше примеров).

## 🔌 RS485

Протокол обмена — эхо по строкам (`\n`). Трансивер переключается `RS485_DE` HIGH → передача, LOW → приём. Обязательно установите терминальные резисторы **120 Ом** на концах линии.

## 🔘 Поведение кнопок

- **Короткое нажатие** — индикация `PRESSED`
- **Удержание > 1 сек** — сброс счётчика энкодера в 0

## 📜 Соответствие ГОСТам безопасности

Алгоритм пуска и блокировок соответствует требованиям:
- **ГОСТ Р МЭК 60204-1** (электрооборудование машин)
- **ГОСТ 12.2.003-91** (общие требования безопасности)
- **ГОСТ ISO 14119** (блокировочные устройства)

Подробный анализ и рекомендации — в документе:

**→ [docs/GOST_SAFETY.md](docs/GOST_SAFETY.md)**

> Полные тексты ГОСТов в репозиторий не включаются (авторское право). Их можно получить на [protect.gost.ru](https://protect.gost.ru).
