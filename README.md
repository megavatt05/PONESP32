# PONESP32

Система управления **намоточным станком** на базе частотного преобразователя **EasyDrive MINI-S** + ESP32 / HMI.

Проект построен по принципу **Fail-Safe** и соответствует требованиям **ГОСТ Р МЭК 60204-1**.

## Кратко об алгоритме

1. Постоянный опрос статуса и аварий ПЧ (3000H / 3001H).
2. Кнопка «Пуск» заблокирована, пока нет готовности.
3. Предустановка безопасной частоты 10 Гц.
4. Пуск только по команде оператора.
5. Мониторинг оборотов (1004H) и Watchdog связи.
6. Аппаратная защита двери (геркон → DI3) и E-Stop.
