# ESP32-C3 → EasyDrive MINI-S + Wobble/Traverse

**ESP-IDF 6.1.0** | Fail-Safe | UART + **качающаяся частота**

## Зачем Wobble

Частота плавно качается вокруг базы (например 40 ± 2 Гц) по треугольнику — витки ложатся ромбиком, без навалов на краях катушки.

Два способа:
1. **Встроенный** в EasyDrive (параметры P7.xx) — см. `docs/10_WOBBLE_TRAVERSE.md` в `main`
2. **Программный** на ESP32 (команда `W`) — реализован в этой прошивке

## Команды UART (115200)

| Клавиша | Действие |
|---------|----------|
| `D` | Пуск |
| `S` | Стоп |
| `R` | Сброс ошибки |
| `+` / `-` | Базовая частота ±1 Гц |
| **`W`** | **Wobble ВКЛ/ВЫКЛ** |
| `[` / `]` | Амплитуда ±0.5 Гц |
| `{` / `}` | Период ±1 с |
| `H` | Справка |

По умолчанию: база **40 Гц**, амплитуда **±2 Гц**, период **10 с**.

## Пины RS485

TX=7, RX=6, DE=5 @ **19200** 8N1

## Параметры EasyDrive

```
P13.00=1  P13.01=4  P13.02=0  P13.03=1.0  P13.04=0
P05.02=11   # геркон → DI3
```

Для аппаратного Wobble на ПЧ — группа **P7** (см. документацию в main).

## Сборка

```bash
git clone -b esp32c3-modbus-rtu https://github.com/megavatt05/PONESP32.git
cd PONESP32 && pio run -t upload && pio device monitor
```
