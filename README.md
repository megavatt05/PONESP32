# PONESP32

Система управления **намоточным станком** на базе частотного преобразователя **EasyDrive MINI-S** + ESP32 / HMI.

Проект построен по принципу **Fail-Safe** и соответствует требованиям **ГОСТ Р МЭК 60204-1**.

## Кратко об алгоритме

1. Опрос статуса/аварий ПЧ → «Пуск» заблокирован  
2. Предустановка 10 Гц → «Пуск» разрешён  
3. Команда оператора → разгон  
4. Рабочая база (напр. 40 Гц) + **Wobble ±2 Гц** (укладка)  
5. Мониторинг RPM, Watchdog, геркон, E-Stop
